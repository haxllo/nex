Power menu with lock, sleep, shutdown, restart, sign out from the overlay footer, plus a separate DWM popup in idle state. Uninstaller option to delete settings. Popup resize, text quality, and focus-loss dismissal all stabilized.

## Changelog (24 commits since v2.10.0)

### Features

- **Power menu**: Lock, Sleep, Shutdown, Restart, Sign Out from the overlay footer
- **Idle power popup**: separate DWM-framed window when no results are shown
- **In-overlay confirm panel**: Shutdown/Restart now require confirmation, matching the popup flow
- **Uninstaller settings opt-in**: checkbox to delete user config and index on uninstall

### Bug Fixes

- **Popup resize**: window now resizes correctly between menu (130px) and confirm (150px) views — IPC was reading wrong JSON path, never worked before
- **Confirm→menu resize**: cancel button now shrinks the popup back to menu width
- **Resize on re-open**: popup always starts at menu size, no longer stuck at confirm width between opens
- **Text quality**: DWM popup WebView now loads InterVariable font (was falling back to Segoe UI)
- **Text rendering**: added `text-rendering: optimizeLegibility` matching the overlay
- **DWM double border**: removed CSS borders from popup panels — DWM provides window-level rounded corners
- **Focus-loss dismissal**: clicking outside Nex with popup open now properly hides the overlay (was stuck visible)
- **Power popup focus**: escape suppression, 300ms retry loop, spurious WM_KILLFOCUS grace period

### Architecture

- **power_popup.rs**: standalone tao+wry window with own WebView, DWM rounded corners, frameless WS_POPUP
- **Font extraction**: `@font-face` block extracted from style.css and injected inline into popup HTML
- **Size management**: JS reports hardcoded widths (130/150px), Rust resets size synchronously on show
