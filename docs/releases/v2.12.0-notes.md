# Nex Windows Milestone Release Notes

## Release Metadata

- Version: `2.12.0`
- Build date (UTC): `2026-08-04`
- Artifact: `artifacts/windows/nex-2.12.0-windows-x64.zip`
- Manifest: `artifacts/windows/nex-2.12.0-windows-x64-manifest.json`

## Highlights

- **Grid View quick-launch layout.** Overlay panel now supports a configurable CSS grid layout for pinned quick-launch items (`grid_view` setting in config). Toggle between list and grid views from the tray context menu.
- **Right-click context menu on result items.** Right-click any result to access actions: run as admin, copy path, open containing folder, and uninstall. Context menu dimensions measured per-open for correct positioning at screen edges.
- **Web icons: 128px themed PNGs with web search row.** Quick-launch icons upgraded from 24px placeholders to full 128px themed PNGs rendered via WebView2. Dedicated web search row with inline icon support added to the overlay.
- **IShellItemImageFactory primary icon extraction.** New icon pipeline uses IShellItemImageFactory as the primary path for high-quality app icons, with StretchBlt fallback for undersized bitmaps. Significant icon clarity improvement on high-DPI displays.
- **Uninstaller improvements.** Start-menu shortcut pruning now handles multiple shortcut variants per entry. Stale index rows purged automatically on uninstall. Added Appx package detection for Store-installed apps.
- **Power popup fixes.** Resolved sizing and positioning issues with the power/action popup menu.

## Changes & Fixes

- Grid View toggle via tray context menu, persisted to config.
- Context menu: run-as-admin triggers `AllowSetForegroundWindow` for proper focus transfer.
- Context menu: pin/unpin toggle, copy path corrected for quoted paths.
- Quick-launch: `auto_fill` defaults to `false`; migration handles missing key gracefully.
- Quick-launch: `find_item_by_path_or_title` supports partial title and path matching.
- Quick-launch: duplicate unpin code removed, variable reference bugs fixed.
- Overlay: panel resize/height fixes for idle→results and quick-launch→search transitions.
- Overlay: defer result visibility until panel resize completes to prevent content flash.
- Overlay: pre-size window from row count before pushing state for smoother transitions.
- Overlay: hide results body during row swap to prevent quick-launch row leak.
- Publisher subtitle displayed on quick-launch pinned items.
- Uninstall: accepts direct app names in addition to executable paths.
