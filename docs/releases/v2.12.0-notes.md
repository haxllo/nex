Grid View quick-launch layout and right-click context menus land in Nex 2.12.0, alongside 128px themed web icons, IShellItemImageFactory icon extraction, AppxPackage uninstall detection, and a fresh batch of overlay resize/transition fixes.

## Changelog (41 commits since v2.11.0)

### Performance

- **IShellItemImageFactory icon pipeline**: primary icon extraction path with StretchBlt fallback for oversized bitmaps — sharper icons on high-DPI displays.
- **Icon extraction size bump**: fallback size 32→64px for grid view clarity.

### Features

- **Grid View**: quick-launch pinned list redesigned as CSS grid, configurable via `grid_view` setting + default invocation (Win key).
- **Context menu on results**: right-click context menu with run as admin, copy path, open containing folder, uninstall, and pin/unpin toggle.
- **Web search row**: full-width web search row with 128px themed PNG icons for web and quick-launch items.
- **Uninstallable Appx**: autodetected Appx package groupable uninstall with start-menu shortcut pruning and stale index row purge.

### Bug Fixes

- **Overlay resize**: quick-launch body hidden during row swap to prevent flash; bypass resize debounce for idle→results growth; pre-size window from row count before pushing state.
- **Quick-launch transitions**: hide rows on query, track `hadQuickLaunch` to skip stale resize on QL→search; defer measure by one rAF on idle→search; reset height tracker on idle→search.
- **Context menu**: measure size per-open instead of cached; accept direct app names for uninstall; fix clip at screen edges.
- **Quick-launch config**: `auto_fill` defaults to false; migration guard for `unwrap_or`; remove duplicate unpin code; partial title/path match in `find_item_by_path_or_title`.
- **Power popup**: hide overlay synchronously with popup on click-away; suppress DWM show/hide animation.
- **General overlay**: default Win key + grid view; fix copy/open-folder/uninstall paths; run-as-admin `AllowSetForegroundWindow`; hide unpinned add-icon; pin toggle in menu; copy path fix.

### Architecture

- **Grid View layout**: CSS grid replaces flex-based quick-launch row layout, enabling themed 128px icons and dynamic column count.
- **Icon pipeline**: `IShellItemImageFactory` added as primary extraction path; StretchBlt fallback handles oversized bitmaps from shell integrations.
