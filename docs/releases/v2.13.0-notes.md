Nex 2.13.0 brings type-to-create actions — unmatched queries now offer folder creation (trailing `\`), file creation (known extensions), and bare-domain URL opening in your default browser — plus a hardened search backend: tantivy fields are stored (fixing vanished app types), a single writer with re-seed, and mid-run self-healing when the index schema changes. Icon extraction is now icon-only (no more file thumbnails) at 256px native resolution, and a batch of overlay resize/row fixes land, including an integral 46px row height that eliminates the 1px bottom strip on small windows.

## Changelog (50 commits since v2.12.0)

### Features

- **Create folder on unmatched query**: type a path ending in `\` (e.g. `D:\projects\new\`) → "Create folder" row; nested paths allowed, illegal characters rejected, existing paths offer "Open folder". Configurable target via `default_create_dir`.
- **Create file on unmatched query**: whitelisted extensions (`create_file_extensions`, 18 common types) → "Create file" row using `create_new` (never overwrites); Windows reserved names (CON, PRN, NUL, COM/LPT…) rejected.
- **Open URL on unmatched query**: bare domains (`youtube.com`) and explicit `http(s)://` URLs → "Open in browser" row via `open_url_in_default_browser` + `url_tlds` (32 TLDs); also reachable in command mode (`> youtube.com`).
- **Fresh installs index files + folders by default**: `show_files`/`show_folders` now default to true; upgrading users keep their existing config.
- **Custom folder + file placeholder icons**: Explorer shell icons replaced with bundled themed icons until real icons load.
- **Extended built-in excludes**: AI CLI workdirs, rustup toolchains, WebView caches, dev cache dirs, shell artifacts.
- **Kind-first result ordering**: apps hoisted above files/folders in the tantivy path, tier-aware regrouping, BM25 as within-tier signal, dedupe-before-top-hit guard.

### Bug Fixes

- **Tantivy schema**: `kind` and `subtitle` are now STORED — previously they were indexed-only, so every tantivy result read back an empty kind, breaking app hoist and grid rendering.
- **Tantivy writer**: single writer instance + re-seed on open (kills dual-writer meta.json corruption); empty index re-seeds live.
- **Mid-run index self-heal**: schema mismatch/corruption now resets and rebuilds during the next sync — no restart required.
- **TopHit row**: only rendered for apps; non-app results group under section headers; single non-app result no longer vanishes.
- **1px bottom strip**: row height was fractional (46.22px) — `Math.ceil` window sizing left an unpainted strip; rows are now an integral 46px.
- **Icon extraction**: icon-only flags (no thumbnails), native-size canvas for small icons (no upscale blur), 256px request for all items.
- **Overlay resize**: immediate resize on structural transitions (grid flips, action rows), immediate growth on row-count jumps, synchronous shrink, stable grid columns via scrollbar-gutter.

### Architecture

- **Creation actions registry**: action rows (folder/file/URL/web) injected in the search session merge with exact-title-match suppression; dispatch through `launch_path` / `launch_open_target`.
- **Icon pipeline**: single reset helper shared by boot-time and mid-run tantivy recovery paths.
