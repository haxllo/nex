Quashes three overlay bugs — selection now maps through `result_index` instead of raw DOM row position (fixing wrong-item activation in file/folder results), tray-quit no longer blocks the main thread or flashes a console window on release builds, and icons with sparse alpha fill are cropped and Lanczos-upscaled to fill the 128px canvas. Also hardens instance signaling (PID-scoped), event-loop teardown, and panic diagnostics.

## Changelog (4 commits since v2.13.0)

### Bug Fixes

- **Selection wrong item**: JS row position included section headers — submit now maps through the row's `result_index` field to the correct result.
- **Sparse glyph icons**: icons with low alpha fill (Magnifier, JPEGView glyphs ~12%) are cropped to their visible glyph and Lanczos-upscaled to fill 128px; full-bleed icons pass through unchanged.
- **Tray quit freeze + console flash**: `taskkill` spawns now use `CREATE_NO_WINDOW` at shutdown + hotkey recovery/reconfig threads.
- **Instance signaling**: PID-scoped signals, event-loop teardown guards, panic backtraces + WebView2 death logging.
