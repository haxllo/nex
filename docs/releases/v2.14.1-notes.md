## Changelog (21 commits since v2.14.0)

### Performance

- **No-resize typing**: keyed row reconciliation (`role|kind|title|subtitle|icon` stable keys) — unchanged `<li>` nodes reused in place, no image re-decode, no entrance re-animation on surviving rows.
- **Zero-flash resize**: WebView viewport pinned at MAX_HEIGHT — the window clips a pre-rasterized surface, so grow/shrink never exposes the acrylic backdrop.
- **Immediate resize**: shrink and small-grow apply instantly (settle timers removed — pre-rasterization made them unnecessary); `lastH` dedupe keeps ≤1 resize per frame.
- **Icon pipeline**: blank 1px-GIF cold-cache slot (no wrong-glyph flash), pop-in animation gated on real src swap, `reduceMotion` respected.

### Bug Fixes

- **Folders missing from search**: compaction retained files before folders (row-id order) — folders now retained first, then files fill remaining cache slots.
- **First-keystroke desktop peek**: quick-launch rows no longer hide instantly on typing (leftover pre-reconciliation hack) — window holds its height through the first search.
- **Window lag on result reduction**: 350ms shrink settle removed — window follows content instantly (apps-only grid shrinks included).
- **Acrylic flash on resize**: viewport pre-rasterization (above) — was the blank-WebView → backdrop show-through.
- **Stale accent/theme**: re-detected in the Show handler; acrylic tint re-applied while invisible.
- **Selection/context actions on reused rows**: handlers read live `dataset.index` + current row snapshot.
- **Pin/unpin icon staleness**: `set_status_text_and_refresh` pushes full state for pin/unpin/add; pure status messages use lightweight `ApplyStatus` (Copy Path no longer re-renders results).
- **Context menu**: Run-as-admin hidden on folders; dividers auto-hidden when adjacent sections empty.
- **Tantivy diagnosability**: open-failure, reset, and committed-doc logging.
- **(earlier, unreleased)**: click-outside instant hide (WH_MOUSE_LL), 450→150ms deferred-hide cut, grid arrow-key navigation, Painted show gate.

### Architecture

- **Sizing pipeline simplified**: JS measures once per render, posts `immediate:true`; host applies synchronously and re-asserts the oversized viewport after wry's WM_SIZE snap.
