This one's mostly about things I kept bumping into myself: nex feeling slow to wake up, settings pages having no icons, and search hiding files on short queries. All of that's fixed, plus a bunch more Settings pages.

**Startup is now instant.** The old startup spent over a second warming up a PowerShell process just to check if the helper task exists — that's gone, replaced with a native `schtasks` query (~30ms). Even better, the hotkey now registers first and the elevated helper connects in the background, so nex answers your hotkey almost immediately instead of making you wait. There was also a nasty bug where the watchdog thought the hotkey died after the helper took over and kept restarting it — that freeze you saw once is fixed for good.

**Search actually searches now.** Files, folders and Settings pages were invisible on 1-2 letter queries because those short queries only searched the app cache. Now they search everything, with apps still staying on top. No more typing "d" and wondering where your Downloads folder went.

**Settings got a big upgrade.** All 59 original pages now show real per-page icons instead of placeholders (a classic GDI quirk: it writes text without touching the alpha channel — one of those hour-long bugs). The catalog also grew from 59 to 108 pages: Advanced display, Recovery, Storage Sense, Lock screen, Themes, Installed apps, Windows Security, Update history, and friends. "Advanced system settings" is there too, launching the good old Control Panel dialog — it never got a modern page.

Small stuff: icons of all sizes now normalize to a consistent canvas (no more huge Spotify next to tiny Settings), grid tiles lost their faint background, the power menu pops in with a little animation, and Settings rows no longer show a redundant "ms-settings:..." subtitle.

## Changelog

### Performance
- Startup: hotkey hook registers first (~30ms), elevated helper connects async in the background; hotkey live almost immediately instead of after ~1.5s
- Scheduled-task existence check swapped from PowerShell (~1s CLR cold start) to `schtasks /query /xml` (~30ms)

### Features
- Short queries (1-2 chars) now search the full pool — files, folders and Settings pages visible, apps still ranked on top
- Settings catalog expanded 59 → 108 pages; "Advanced system settings" added via `sysdm.cpl` with its real Control Panel icon

### Bug Fixes
- Settings page icons were invisible (GDI text doesn't write the alpha channel) — glyph alpha is now derived from luminance, real icons show
- Hotkey watchdog restart loop after helper handover (the freeze) — `is_alive` now trusts the helper path
- Settings rows showed "ms-settings:..." as subtitle — hidden
- Small icon sources now normalized to a uniform 128px canvas (Spotify 256px vs Settings tiny)
