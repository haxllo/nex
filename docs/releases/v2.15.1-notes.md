Hotfix release for the freeze that could happen right after installing 2.15.0. The launcher now opens the instant you press the hotkey, even while it's still building the search index in the background, and two startup crashes from a WebView2 race are gone for good.

## What changed

- **Launcher opens instantly**: pressing the hotkey while the index was still building used to stall the whole app until the build finished — the window only appeared seconds later, and your keystrokes got stuck and fired late. The window now shows up immediately and fills in the results as soon as the index is ready.
- **Fixed a crash on first run after install**: the power menu popup and the main search window both tried to start their web engine at the same time, and that race made the search window hang so the hotkey did nothing until you restarted the app. The popup now starts only after the main window is fully ready.
- **Fixed a crash in dev mode**: opening the launcher from a dev build could hit the same race and freeze the PC. The window now just waits for its content instead of tearing itself down and rebuilding.
- **No more surprise UAC prompt on first launch** (all-users installs): the helper task is set up during installation instead of on the first hotkey press.
- **Search index corruption recovers faster**: if the index gets damaged (e.g. the app is killed mid-write), the next start rebuilds it silently in the background instead of blocking startup.
