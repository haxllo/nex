Nex 2.16.0 is a big interaction release: a redesigned power menu built into the main window, a new "Show all apps" expansion that turns any query into your full app list, and a long list of fixes to how rows highlight, animate, and resize.

## What changed

- **Power menu**: the separate popup window is gone. Clicking the power icon now opens an inline panel with six action tiles — Back, Lock, Log Out, Sleep, Restart, Shut Down — each with its accent color and dot indicator, plus an in-panel confirm step for destructive actions.
- **"Show all apps"**: every search with app results ends with a *Show all apps* entry. Activating it keeps your matched apps on top (score order) and appends the rest of your installed apps right below — no re-search delay, no layout jumping. The window grows once; nothing flashes.
- **Power icon moved up**: the power button now lives permanently in the search bar instead of the footer, so it's available in every state.
- **Footer hints** appear only while you're viewing regular results — not on the idle window or quick-launch view.
- **Folder paths on hover**: hovering a folder result reveals its full path on the right side of the row.

### Performance

- **Startup indexing no longer walks every file**: a volatile change-detection stamp forced nex to re-scan ~13k files on every launch even when nothing changed. The stamp is now config-based, so warm starts skip the walk entirely.
- **Search index recovery**: after an unclean shutdown, opening the search index could fail and trigger a full rebuild; transient failures are now retried before anything gets deleted.
- **Icon loading**: large result lists no longer stall rendering — icons swap in with one batched animation instead of forcing a layout pass per image.
- **Window resizing**: large height jumps (like Show-all-apps) apply immediately instead of waiting out the resize debounce, so content never paints before its window.

### Bug Fixes

- **Restart/shutdown error dialog**: confirming restart or shutdown from the power menu could surface an out-of-memory style error from the web engine while the system tore down graphics. The overlay now hides first and the command runs fire-and-forget.
- **Selection highlight ghosts**: stale highlights could linger on the wrong row after typing or expanding results. Highlight now comes only from real cursor hover; selection itself stays invisible but still drives Enter.
- **Results kept your old scroll position** when you typed a new query — they now always start at the top.
- **Row entrance animation replayed on every keystroke** — it now plays once for the first results, then everything renders instantly.
- **Quick-launch grid spacing and padding** tightened to match the rest of the UI.
- The power menu no longer stays open if you hide and reshow the overlay mid-menu, and its confirm view lost a stray divider line.
- Overlay spawn position moved down slightly (30% of screen height) so it doesn't crowd the top edge.

### Architecture

- **Inline power menu**: removed the separate popup window (~650 lines) in favor of an in-flow panel measured by the same resize pipeline as the results list.
- **Two-phase expansion**: Show-all-apps renders a first page synchronously and trails the remainder in, keeping the single-resize guarantee regardless of index size.
