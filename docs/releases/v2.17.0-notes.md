Nex 2.17.0 is a major UI release: a fully redesigned Settings window with premium monochrome styling, custom dropdowns, native hotkey capture, and an overlay footer with a settings button — plus an MIT license agreement in the installer.

## What changed

- **Settings window redesign**: completely rebuilt with a left-nav + right-content layout, custom title bar, and monochrome accent theme. The window is now 790x560 with a 42px custom title bar (minimize/close buttons preserved).
- **Custom dropdown components**: all `<select>` elements replaced with custom popup dropdowns featuring checkmarks, keyboard navigation, scroll support, and fixed positioning.
- **Native hotkey capture**: settings page uses WM_INPUT recorder for direct hotkey capture instead of relying on modifier key state polling.
- **Overlay footer settings button**: a gear icon in the overlay footer opens the Settings window directly. Hidden in quick-launch mode.
- **Hotkey moved to General page**: relocated under the top group with Launch at Startup for better discoverability.
- **MIT license agreement**: installer now shows the MIT license for user acceptance before installation.
- **Updater shows installer window**: "Check for Updates" now displays the full installer UI so users can review and accept the license.

### Settings Fields

- Grid View, Show Files/Folders, Launch at Startup
- Quick Launch: enable, auto-fill, max items
- Search: mode default, DSL syntax, web search provider, max results, index size cap
- Hotkey (with native capture chip)

### Overlay Footer

- Hints left-aligned, settings gear icon right-aligned
- Quick-launch mode: footer hidden (6px height spacer provides bottom gap)
- Normal mode: 46px footer with hints and settings button

### Bug Fixes

- **Toggle off background**: fixed to #1A1A1A to contrast with row background #242424
- **Focus outline removed**: Cancel button no longer shows blue focus ring
- **Row background fixed**: #242424 never changes on hover
- **Footer modes**: proper idle/ql/websearch class toggling prevents layout jumps
- **Settings IPC**: "settings" message from overlay correctly opens the Settings window

### Architecture

- **Settings snapshot**: all config fields exposed in settings snapshot JSON for read/write via IPC
- **SearchMode/WebSearchProvider enums**: added `as_str()` and `parse()` methods for config serialization
- **Custom dropdown data**: options passed via `data-options` JSON attribute on select elements
- **FIELDS array**: settings.js supports `"checked"`, `"valueNumber"`, `"valueSelect"` field kinds
