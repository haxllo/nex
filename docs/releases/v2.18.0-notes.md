## Faster Search, Clipboard History, and Safer Settings

Nex 2.18.0 makes search modes easier to discover, adds a visual clipboard history, and makes settings changes safer to close. The overlay also gets cleaner spacing, hover feedback, and power controls.

## What changed

- **Direct search modes**: type `@apps`, `@files`, or `@folders` to immediately browse that category. Files and folders are now separate results.
- **Mode autocomplete**: typing `@` suggests available modes and Tab completes them.
- **Clipboard history**: open Clipboard to browse captured text and images in a bento-style history view.
- **Safer settings**: closing settings with unsaved changes now asks whether to save or discard them. Saving waits for the asynchronous write to finish before closing.
- **Overlay polish**: reduced overlay width, added result/footer spacing, and refined list, grid, and power-menu interactions.

### Features

- **Clipboard history bento view**: copy previous text or image entries directly from the visual history.
- **Mode-specific search**: `@apps`, `@files`, `@folders`, `@all`, `@actions`, and `@clipboard` are supported with autocomplete.

### Bug Fixes

- **Settings save race**: closing immediately after Save changes could hide settings before the save completed. Close now waits for successful save confirmation.
- **Duplicate folder paths**: removed the duplicate right-side path shown while hovering folder results.
- **Command-mode parsing**: fixed `@clip` and related command parsing so mode tokens and commands resolve consistently.

### Architecture

- **Search mode model**: removed redundant `kind:` filtering in favor of explicit `mode:` and `@` mode selection.
- **Overlay state handling**: separated result hover layers from row content so hover effects do not move text or icons.
