## Reliability and Windows UX

Nex 2.19.0 fixes several Windows lifecycle, search, persistence, accessibility, and overlay interaction bugs. The launcher should now behave more predictably when opened over the desktop, reused repeatedly, or driven entirely from the keyboard.

**GitHub release title:** `v2.19.0`

## What changed

- **Windows overlay lifecycle**: Opening and closing Nex over the bare desktop no longer activates the shell in a way that flashes the auto-hide taskbar. Repeated hotkey toggles keep working after the first cycle.
- **Power menu**: Flattened power controls and made Back a compact icon-only button with a clear hover state.
- **Settings navigation**: Left-side navigation buttons now have consistent sizing, alignment, keyboard behavior, and focus handling.
- **Search selection**: Keyboard selection takes priority over a stationary mouse hover, leaving one clearly selected result.

### Bug Fixes

- **Filesystem watcher safety**: Bounded shutdown waits, validated notification buffers, preserved rename direction, and removed stale or duplicate indexed paths.
- **Clipboard history**: Fixed cache cross-contamination, stale results after clearing, unsafe image-buffer reads, and interruption-prone history writes.
- **Search state**: Prevented stale results after configuration reloads and stopped unnecessary cache invalidation on unrelated runtime events.
- **Quick Launch**: Enforced maximum item counts and filled remaining slots after pinned entries when auto-fill is enabled.
- **Calculator**: Corrected unary-minus precedence and rejected oversized expressions.
- **Windows positioning**: Corrected physical-pixel centering for settings windows across DPI configurations.
- **Tray and updater**: Removed duplicate tray activation and restricted updater script discovery to executable-relative locations.
- **Accessibility**: Added search labeling, stable active-result IDs, keyboard settings navigation, focus outlines, and modal focus trapping.
- **Database startup**: Serialized schema migrations to prevent concurrent initialization races.

### Architecture

- Watcher resources now shut down through their normal ownership path instead of being intentionally leaked.
- Search results carry configuration generation metadata so old worker responses are discarded safely.
