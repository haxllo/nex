## Web Bookmarks & Quick Launch Overhaul

The big addition this release is web bookmarks — save any URL, see its favicon, open it in your browser, and pin it to Quick Launch like any other result. We also spent significant time fixing context menus (they used to clip, dismiss randomly, or show the browser's built-in menu instead of ours) and making search results cleaner by deduplicating before display.

**GitHub release title:** `v2.20.0`

## What changed

- **Web bookmarks**: You can now save URLs as persistent bookmarks, complete with favicons and context actions. They show up in search and can be pinned to Quick Launch just like apps.
- **Context menus**: Completely reworked — they now stay within the viewport, size correctly for their content, dismiss reliably on keyboard input, and no longer fight with Chromium's native right-click menu.
- **Search deduplication**: Results are deduplicated before the limit is applied, so you no longer see duplicate entries crowding out other matches.
- **Website Quick Launch**: Websites can now be pinned to Quick Launch with proper title display, favicon sharing between search and the launch panel, and clean handling of legacy pins from earlier versions.

### Features

- **Persisted web bookmarks**: Save and manage URLs as first-class bookmarks with local storage.
- **Bookmark context actions**: Right-click bookmarks for actions like open, pin, and remove.
- **Bookmark favicons**: Bounded favicon cache loads and displays website icons next to bookmark results.
- **Open bookmarks in browser**: Bookmark results launch directly in your default browser.
- **Website Quick Launch pinning**: Pin any website result to the Quick Launch panel.
- **Website favicons in search**: URL results now display their site favicon alongside the title.

### Bug Fixes

- **Context menu clipping**: Menus no longer get cut off at the edges of the overlay.
- **Context menu viewport clamping**: Menus reposition themselves to stay fully visible.
- **Context menu focus**: Keyboard dismissal is now reliable — pressing Escape or typing closes the menu immediately.
- **Native Chromium menu suppression**: Right-clicking a bookmark no longer shows the browser's built-in context menu.
- **Context menu sizing**: Bookmark context menus size correctly for their content.
- **Context menu positioning above short results**: Menus now appear above the result row when there isn't enough space below.
- **Website Quick Launch title display**: Pinned websites now show their proper title instead of a raw URL.
- **Legacy website Quick Launch pins**: Pins from earlier versions are handled gracefully — removed cleanly without errors.
- **Quick Launch settings pins**: Settings entries pin and unpin correctly from the Quick Launch panel.
- **Quick Launch visuals**: Improved spacing and alignment in the Quick Launch panel.
- **Search result deduplication**: Duplicate results are removed before the result limit is applied, giving every unique item a fair shot at appearing.
- **Uninstall wrapper deduplication**: Uninstall entries wrapped by Windows no longer appear as separate duplicate results.
- **Direct website result priority**: Direct URL matches now rank above fuzzy search results.
- **Favicon cache sharing**: Search and Quick Launch share a single favicon cache instead of each maintaining their own.
- **Direct URL favicon validation**: Favicon requests for direct URLs are validated before fetching.
- **Credential-bearing bookmark URLs**: Bookmarks with embedded credentials (user:pass@host) are rejected to prevent accidental credential exposure.
- **Tantivy index refresh**: The search index refreshes properly after a full index replacement.
- **Launch metrics preservation**: App launch frequency data survives index rebuilds.
- **Website result metadata**: Website results preserve all their metadata (URL, title, favicon) across sessions.
- **Settings menu dismiss on typing**: The settings context menu closes when you start typing.
- **Pinned settings unpin**: Pinned settings entries can be unpinned from Quick Launch.

### Architecture

- **TOML config migration**: Configuration is now fully TOML-based; JSON/JSON5 backward compatibility is preserved but no longer the default.
