# v2.21.0 — Performance & Windows Integration

This release makes Nex faster and more reliable on Windows. Search responds quicker on single keystrokes, indexing is more robust, and you get better diagnostics when something goes wrong.

**GitHub release title:** `v2.21.0`. Keep descriptive release title in this body heading. Do not use `v2.21.0 — Performance & Windows Integration` as GitHub release title.

## What changed

- **Search speed**: Single-character queries now respond much faster because the results are cached in advance
- **Indexing reliability**: The file watcher recovers better when it misses changes, so your index stays up to date
- **Diagnostics**: You can now see detailed metrics about indexing, search coalescing, and launch failures
- **App metadata**: Store apps show better publisher information in search results
- **App ranking**: Nex remembers which apps you launch and surfaces them more often

### Performance

- **Hot-prefix cache**: Precomputes results for single-character queries so the first keystroke is instant
- **Request coalescing**: Logs when rapid typing merges multiple search requests, which helps diagnose typing issues
- **Memory tracking**: Tracks memory usage across indexing cycles to catch leaks

### Features

- **Structured launch diagnostics**: Launch failures now report what kind of item failed, the path, and the error code
- **Enhanced diagnostics bundle**: Includes indexing metrics, search coalescing activity, and launch failure counts
- **Better Store app metadata**: UWP/Store apps show improved publisher names from package data

### Bug Fixes

- **Launch ranking**: Persistent launch usage now correctly updates use count, launch count, and last accessed time
- **Watcher overflow**: The file watcher now detects when it misses events and triggers a resync to recover

### Architecture

- **Schema version bump**: StartMenuAppDiscoveryProvider bumped to version 8 to invalidate cached app discovery with new metadata behavior
