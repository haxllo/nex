# v2.21.1 — Icon Cache Fix

This release fixes an issue where icon improvements from v2.21.0 were not being applied due to cache invalidation not working properly.

**GitHub release title:** `v2.21.1`. Keep descriptive release title in this body heading. Do not use `v2.21.1 — Icon Cache Fix` as GitHub release title.

## What changed

- **Icon cache fix**: Bumped icon normalization version to force cache clearing
- **Reindex trigger**: Bumped discovery schema version to force app reindexing
- **Text rendering**: Added subpixel antialiasing and geometric precision for sharper text

### Bug Fixes

- **Icon cache invalidation**: Icon improvements from v2.21.0 now properly clear old cached icons
- **Discovery schema**: Apps will reindex with improved icon extraction algorithm
- **Text sharpness**: Text rendering improvements from v2.21.0 are now properly applied
