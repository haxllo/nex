## Update notifications and safer updating

Nex now tells you when a newer release is available and gives the update process clearer feedback. The updater is more compatible with older Windows PowerShell environments and starts the refreshed runtime directly after installation.

**GitHub release title:** `v2.21.2`

## What changed

- **Update notice**: Nex checks for updates at startup and shows an update button only when a newer stable release exists.
- **Update feedback**: The button now shows `Updating...`, `Updated`, `Up to date`, or `Retry` instead of silently launching a background process.
- **Settings version**: Settings now displays the running app version in its footer.

### Bug Fixes

- **Updater compatibility**: Fixed failures on Windows PowerShell versions without `Get-FileHash`, `ConvertFrom-Json -Depth`, or empty `Start-Process -ArgumentList` support.
- **Update restart**: The updater starts the new runtime directly in foreground mode, avoiding an unnecessary background-to-foreground startup race.
- **Installer activation**: Added foreground activation requests from Nex and the installer itself.

### Architecture

- **Startup-only checks**: Removed hourly background update checks to avoid unnecessary network activity and notifications.
- **Release validation**: Installer downloads remain protected by manifest and SHA-256 verification, with a .NET hashing fallback.
