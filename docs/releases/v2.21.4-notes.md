## Automatic silent updates

Pressing Update now completes the whole installation by itself. The updater no longer stops halfway, and the installer no longer asks for Next/Next confirmation.

## What changed

- **Automatic installation**: After downloading and verifying the update, Nex installs it without opening the interactive setup wizard.
- **Silent progress**: Installation shows progress without wizard prompts, cancellation, restart prompts, or startup dialogs.
- **Preserved scope and location**: Automatic installs reuse the existing per-user or all-users scope and install directory.
- **Installer diagnostics**: Every automatic install writes a setup log next to the downloaded update files.
- **Reliable restart**: The installer no longer launches Nex itself during updates; the updater verifies the new runtime and restarts it.

### Bug Fixes

- **Updater self-termination**: Runtime shutdown no longer terminates the updater process before installation and restart can run.
- **PowerShell compatibility**: Installer arguments use a single quoted string instead of an array that older Windows PowerShell versions reject.
- **Installer marker**: The updater marker uses Inno-style `/NEXUPDATER` so the installer reliably recognizes updater-driven installs.

### Architecture

- **Updater-owned lifecycle**: Nex supplies foreground permission, the updater owns download, shutdown, installation, verification, restart, and rollback.
- **Explicit install context**: Automatic installs pass scope, directory, logging, and restart behavior explicitly rather than relying on wizard defaults.

### Known issue

- Installs already running an updater older than this release still use that older installed script. Those machines need this fixed release installed once manually; afterward, update-button installs are automatic.
