## Now-playing media widget

Pressing Tab while music or video is playing now opens a media view with album art, a live progress bar, and transport controls — no Spotify account or network needed.

## What changed

- **Media view**: When a media session is active, Tab swaps the search UI for a now-playing view with album art, track details, progress bar with times, and previous/play/next controls.
- **Tab keeps its old job**: With no media playing, Tab still just selects the search input text.
- **Seekable progress**: Click or drag the progress bar to jump within the track.
- **Keyboard control**: `Space` toggles playback, `←`/`→` skip tracks, `Tab`/`Esc` or typing returns to search.
- **Live progress**: The bar and timer glide on a monotonic clock, so late updates never make them jump backward; genuine seeks apply within about a second.
- **Survives hide**: Reopening Nex keeps the media view, and playback ending while hidden closes it automatically.

### Bug Fixes

- **Frozen overlay on media refresh**: Media snapshots moved off the UI thread onto a background worker with a timeout, so a slow session can never wedge the overlay again.
- **Spotify-first sessions**: When several apps play media, the Spotify session is preferred.

### Architecture

- **Windows SMTC integration**: Now-playing state comes from the OS media session manager, with transport commands sent back the same way.
- **Strict IPC additions**: `mediaToggle`, `mediaNext`, `mediaPrev`, `mediaRefresh`, and `mediaSeek` messages follow the existing typed envelope and validation.
