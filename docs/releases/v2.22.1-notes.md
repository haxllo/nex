## Orphaned-install detection and cleanup

Nex now notices when the running copy is not the registered install — the situation where a stale copy silently shadows updates — and the installer removes such orphaned copies during per-user installs.

## What changed

- **Startup skew warning**: On launch, Nex compares its own location against the registered install and logs a loud warning when they differ, naming both paths and what to do about it.
- **Updater skew guard**: The updater refuses to update the registered install while an older orphaned copy is the one actually running, and instead tells you to restart from the installed location.
- **Installer orphan cleanup**: Per-user installs remove a leftover machine-wide `Nex` folder when no registered all-users install exists. Legitimate all-users installs are never touched.

### Bug Fixes

- **False "up to date"**: The updater no longer reports up-to-date based on the registered install while a stale binary actually answers the hotkey.
