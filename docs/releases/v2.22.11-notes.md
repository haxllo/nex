## The overlay is ready to type, with a cleaner glass finish

Nex now hands keyboard focus directly to its search field as the overlay opens, so the first key goes where you expect without an injected system key. Hover states and the power and context menus have also been simplified to fit the rest of the interface.

## What changed

- **Immediate search focus**: The native WebView and its search field both receive focus during show, and foreground activation no longer injects an Alt key.
- **Cleaner menus and hover states**: Row hover is seamless and more softly blurred. Power actions use simpler icon tiles, while context menus use a lighter frosted surface with fewer borders.
- **Liquid glass refinements (opt-in)**: The native refraction experiment now selects the correct displacement channels and uses a gentler, balanced bend to reduce corner divider lines. It remains disabled by default; set `NEX_REFRACT_LAB=1` to enable it.

### Bug Fixes

- **First key after opening Nex**: Native WebView focus is explicitly transferred before the search field is focused, and the synthetic Alt tap that could leave Windows in system-menu handling has been removed.
- **Refraction skew and corner lines**: Correct displacement channels remove the diagonal bias, and the bezel bend is reduced to 10 across the panel.
