## Liquid glass now works out of the box

The native refraction layer is enabled by default, so Nex shows the liquid glass effect without environment setup. If graphics capture cannot start, Nex keeps its Acrylic fallback; setting `NEX_REFRACT_LAB=0` opts out of refraction.

## What changed

- **Default liquid glass**: Refraction starts automatically on launch. Set `NEX_REFRACT_LAB=0` to use the Acrylic fallback for troubleshooting.

### Bug Fixes

- **Refraction required manual setup**: The experimental environment gate is now opt-out, so packaged Nex enables the effect by default.
