## Elevated orphan cleanup

Per-user updates now elevate the installer exactly once when a legacy Nex copy exists outside the registered install, so the orphaned copy and its stale shortcuts are actually removed instead of surviving every update.

## What changed

- **One-time elevation**: When a pre-AppId copy is detected under Program Files with no registered all-users install, the updater launches the installer elevated. Scope stays per-user — the only change is a single UAC prompt for the cleanup.
- **Stale shortcut removal**: The installer also removes the orphaned all-users Start Menu shortcut that kept launching the old binary.
- **Version-only release titles**: Release tooling now requires plain `vX.Y.Z` GitHub titles.

### Bug Fixes

- **Orphan survived updates**: A non-elevated installer physically cannot delete Program Files content, so the previous cleanup entry never took effect. Elevating the installer launch fixes the actual mechanism.
