## Correct elevated orphan cleanup

Per-user updates that elevate to remove a legacy copy no longer flip the install into admin mode. Elevation is only about permission now; the install scope always follows the registered install.

## What changed

- **Decoupled elevation and scope**: Requesting elevation for orphan cleanup no longer passes `/ALLUSERS`. A per-user update stays per-user — files, uninstall entry, and shortcuts all land in the right place.
- **Orphan cleanup actually runs**: With the installer per-user (even when elevated), the legacy-copy guard passes, so `C:\Program Files\Nex` and its stale Start Menu shortcut are really removed.

### Bug Fixes

- **Hybrid installs**: The previous release could register a per-user file install machine-wide, leaving uninstall entries in both hives. Scope can no longer change as a side effect of elevation.
