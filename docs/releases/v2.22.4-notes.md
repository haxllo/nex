## Faster downloads and hybrid-registration cleanup

Downloads no longer crawl, and the installer cleans up the stale machine-wide registration left behind by the previous release's scope bug.

## What changed

- **Fast downloads**: The updater silences PowerShell's per-chunk progress bar, which was throttling multi-megabyte downloads to a crawl.
- **Hybrid registration cleanup**: Per-user installs now remove a stale machine-wide uninstall entry when it points at the very install being updated — repairing the dual-registration state without manual registry edits.

### Bug Fixes

- **Dual Add/Remove entries**: A previous updater could register a per-user file install machine-wide. The leftover entry is now detected by location match and removed; legitimate all-users installs are never touched.
