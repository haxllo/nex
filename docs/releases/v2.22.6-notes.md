## Orphan cleanup that actually runs

The previous release's orphan cleanup could never fire on real hybrid machines: elevation required no machine-wide entry, but the hybrid state always has one. Both the trigger and the installer logic now understand the hybrid state.

## What changed

- **Hybrid-aware elevation**: The updater elevates when a machine-wide entry points outside Program Files (a physical impossibility for legitimate installs), not just when no entry exists.
- **Ordered installer cleanup**: Orphan directory, stale shortcut, and hybrid registry-key removal now happen in one ordered step after install, with the legitimacy check evaluated before any deletion — instead of two split checks that could never agree.
- **Setup log proof**: Every cleanup decision is written to `setup.log`, so silent installs leave evidence of what was removed or deliberately kept.

### Bug Fixes

- **Orphan survived elevation**: Fixed the self-defeating guard where elevating for cleanup also disabled it.
