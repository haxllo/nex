## Update failed with the wrong "all users" error

Sorry about this one. If you pressed update and got told Nex "is already installed for all users" — even though your copy sits in your own user folder — that message was wrong, and the update died because of it. Running the downloaded setup by hand hit the same error. Both work now.

## What changed

- **The copy you run is the copy that gets updated**, silently, in place — yours or the machine-wide one.
- **The leftover entry that caused the false error is removed automatically** during the update instead of blocking it.
- **A real machine-wide install still stops and tells you**, so you can rerun setup as All users or uninstall that copy first.

### Bug Fixes

- Update failing at the end, after showing progress.
- Downloaded setup failing with the same error.
