## The update button is back for per-user installs

If you installed Nex just for yourself and the update button never appeared, this was our bug, not your setup. The updater crashed quietly on machines without a machine-wide install entry — so it never checked, never showed the button, and silently skipped every update. Fixed.

## What changed

- **Updater survives a missing machine-wide entry**: the check that used to kill the whole script now just moves on. Per-user installs get their update button and silent updates back.
- **One manual step if you're stuck**: the broken part is the updater itself, so it can't fix itself automatically. Download the setup below and run it once (Current user is fine) — everything after that updates on its own again.

### Bug Fixes

- Update button never appearing on pure per-user installs.
- Same crash also hardened in the install-path lookup next to it.
