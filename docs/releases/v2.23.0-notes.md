## Chat arrives in Nex, no CLI install needed

Nex grows an in-overlay AI chat: press Tab and ask anything, with the conversation, history, and provider settings living right inside the launcher. The ChatGPT account path is now fully native — sign in through your browser, and Nex handles tokens, refresh, models, and responses itself, so the separate Codex CLI install is no longer required.

## What changed

- **In-overlay chat**: Tab opens a full chat view with streaming answers, markdown, code blocks with copy, conversation history, and a glass message pill.
- **Native ChatGPT sign-in**: Browser OAuth built in. Tokens stay in Nex's own storage (mirrored for the CLI), refresh automatically, and sign-out revokes properly.
- **Model settings that stay out of the way**: Provider and model pickers with auto-loading model lists, floating settings card with blurred backdrop, closes on outside click or hide.
- **Quotas and limits, explained**: Usage-limit hits name their reset time, over-long chats suggest starting fresh, expired sessions ask to reconnect.
- **Message links open**: Links in answers launch in the default browser.

### Bug Fixes

- **Chat window height collapse**: The chat view could open shortened with the message box cut off after hide/show; its height is now fixed instead of viewport-dependent.
- **Settings stuck open**: Model settings no longer survive a hide/show cycle.
- **Double highlights**: The open conversation is marked with an accent bar instead of a second fill, so hover never reads as two selections.
