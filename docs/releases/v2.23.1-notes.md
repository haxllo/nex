## What's New polish and a cleaner footer

Small follow-up to the chat release: the What's New page now scrolls properly with the standard Nex scrollbar, keeps fetched notes across close and reopen, and never stacks on top of chat. The footer Chat button is gone — Tab remains the way into chat.

## What changed

- **Scrollable What's New**: Long release notes scroll inside the view with the standard thin scrollbar instead of clipping the dismiss button.
- **Notes survive close**: Reopening shows cached notes instantly; late fetches render instead of dropping.

### Bug Fixes

- **Stacked views**: Chat and What's New are now mutually exclusive.
- **Footer cleanup**: Removed the Chat button from the footer.
