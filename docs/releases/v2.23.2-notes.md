## Chat reliability fixes

Stopped chats no longer leak their status into new chats, the model list matches the rest of the UI, and background provider calls stay hidden.

**GitHub release title:** exactly `v2.23.2` (version only, no descriptive suffix - the descriptive title lives in this body heading).

## What changed

- **Clean chat switching**: Starting or switching chats resets the status line.
- **Model list viewport**: Shows five options with the standard Nex scrollbar.
- **Quiet background calls**: Provider subprocesses run hidden with no console flash.

### Bug Fixes

- **Stale "stopped" line**: It carried over into fresh chats after stopping a request.
- **Default scrollbar**: The model dropdown used the unstyled browser scrollbar.
- **Console flash and hide**: Opening model/provider controls could flash PowerShell windows and hide Nex.
