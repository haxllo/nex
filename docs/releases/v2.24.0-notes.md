## Chat grows up: file picker, honest PC specs, and a tidier footer

This one makes chat feel like part of Nex instead of bolted on. You can attach files without leaving the overlay, ask about your PC and get a straight answer with real CPU and GPU names, and the whole view got a polish pass — aligned composer, calmer footer, no phantom loading cursors.

**GitHub release title:** exactly `v2.24.0` (version only, no descriptive suffix — the descriptive title lives in this body heading).

## What changed

- **Attach files without leaving Nex**: the paperclip opens a file picker right inside the overlay — This PC, drives, folders — instead of a system dialog that yanked focus away. Pick up to 3 small text files and they ride along with your next message.
- **Back button that actually goes back**: drilling into a drive root used to trap you — no way back to This PC. Back now walks all the way out, and hides itself at the top level instead of sitting there disabled.
- **PC questions get real answers**: asking "what's my GPU?" used to return "unknown" plus PowerShell homework. Nex now reads your actual CPU model, GPU name(s), and installed RAM, and answers as a compact spec table instead of hedging every line. It also stopped reporting fluctuating free-RAM numbers and a meaningless build-architecture line.
- **Your Windows version, stated correctly**: machines upgraded from Windows 10 had their registry frozen at "Windows 10 Pro" even on Windows 11. Nex now derives 10 vs 11 from the build number and prints the full build, e.g. 26300.9550.
- **Copy the whole conversation**: a copy icon next to `+` grabs the full transcript. Both buttons disable on empty chats, so mashing `+` can't pile up blank "New conversation" entries anymore.
- **Footer that lines up**: the input box and footer used to sit 8px off from the messages above. Everything shares one column now; the "What gets sent?" paragraph and the key hint are gone (what's sent is already visible as removable chips).

### Bug Fixes

- **Fake loading cursor**: disabled icon buttons showed a wait spinner on hover even when nothing was loading. They show a normal cursor now; real loading still has its own indicators.
- **Stuck dismissal and vanishing overlay**: opening the attach menu could dismiss the overlay out from under you, and stale timers could close the picker mid-browse. Both fixed.
- **Wrong GPU registry key**: the first cut looked up a display-class key that doesn't exist, so no GPU would ever be found. Points at the real one now.
- **Catalog confusion**: non-selectable ChatGPT models no longer show up as choices, the model catalog parses the current schema, and requests carry the client version.
- **Picker list scrollbar**: the file list used the chunky system scrollbar; it matches the rest of Nex now.
