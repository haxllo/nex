## Your background, your call — plus chat that keeps up

The headline: the panel background is now a setting. Liquid Glass stays for those who love it, but solid black (now the default for fresh installs) and white are one dropdown away — each with readable text, parked glass, and edges drawn for flat paint instead of refraction. Around that, chat got its biggest polish pass yet.

## What changed

- **Background setting (Settings → Display → Background)**: Liquid Glass / Black / White. Black and white paint solid, park the glass capture (no GPU burn), force the matching text palette, and switch live with no restart. Starting opaque no longer kills glass for the session either.
- **Markdown that behaves**: links from bare URLs, `_italic_`/`__bold__` without eating `foo_bar`, nested emphasis and code spans, `#{1,6}` headings, horizontal rules, nested bullet lists, `- [ ]` task checkboxes, indented code blocks, `\` escapes, strikethrough — with `javascript:` URLs still staying dead text.
- **Composer that grows up**: long pastes expand the box (pill relaxes into a rounded box past 3 lines), scroll internally with the Nex scrollbar, keep tools bottom-anchored, and recenter the placeholder when single-line. No morph flash on shape change.
- **Copy transcript + sane new-chat**: copy icon next to `+`, and both disable on empty conversations so blank histories stop piling up.
- **Update flow unblocked**: follow-up chat messages stopped dying with HTTP 400 (assistant history now uses `output_text`); the updater spawns without inheriting file handles, waits for renderers to die, retries longer, and names locking processes in the log when blocked.
- **Quieter chrome**: update and What's New are independent pills; What's New never resumes after hide; footer hints and the sharing paragraph are gone; disabled icon buttons show a normal cursor.

### Performance

- **Glass capture sleeps in opaque modes**: no DXGI duplication running behind a solid panel.

### Bug Fixes

- **Overlay edge saga, closed**: thick double edges, DWM's smaller corner curve behind ours, square DWM borders at the corners, sheared drop shadows, WebView2 square-corner artifacts — each traced to its own painter and fixed (see `docs/issues/overlay-edge-artifacts.md`). Panel radius is 20px everywhere now, with one silhouette per mode.
- **Picker back navigation** reaches This PC from drive roots; back button hides at top level.
- **File picker corners** get a real border; its list uses the Nex scrollbar.
- **Focus outlines** from the OS no longer show in chat.
