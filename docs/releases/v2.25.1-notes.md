## The update button knows when to leave

Small one: after checking for updates and hearing "up to date", the Update pill used to sit next to What's New indefinitely. Now it clears itself on any successful result, leaving only What's New. Failures still offer Retry.

## What changed

### Bug Fixes

- **Update pill lingered after "Up to date"**: the status-only result path set the label but never hid the button. Successful results now hide it immediately and reset local state.
