## Text finally renders right, and the helper grew up

This one started with blurry text and ended with the helper process doing
real work. The overlay reads sharper, shows faster, and the pieces behind
the hotkey behave when the system pushes back.

## What changed

- **ClearType everywhere it can be**: search, rows, hover, media, chat,
  menus. Transparent glass still renders gray by design (nothing to blend
  subpixels against), but black and white modes fringe properly now.
- **No more split first show**: Quick Launch used to pop in after the
  input at startup. A snapshot covers the wait, so reveal happens once.
- **One menu language**: every dropdown shares the same surface, hover
  fill, and left-accent selection. Model picker is a real dropdown;
  custom IDs enter through a Use-query option.
- **Icons fixed for thin sources**: shell items exposing a tiny frame on
  a big canvas now fall through to the dense icon instead of serving small.
- **Corners**: DWM draws the 8px silhouette, panel and rows match it, and
  the border is the system default instead of a dyed guess.
- **Outside clicks dismiss at once**, including with the file picker open.

### Performance

- **Show path**: reveal holds for content instead of flashing idle, capped
  so slow indexing never stalls the window.
- **Auxiliary pipes** (log, sim) connect after detection flows with small
  budgets — a missing helper costs ~1s, never the hotkey.

### Features

- **Helper simulation transport**: allowlisted media and edit chords over
  a dedicated pipe for targets only elevated input reaches.
- **Helper log pipe plus privilege report**: helper diagnostics land in
  the main log; elevation, integrity and UI-access logged at startup.
- **Model fetch retries twice** before failing; chat history, file picker
  and composer follow the shared menu patterns.
- **Task Manager names**: both binaries carry display names.

### Bug Fixes

- **Startup spam chaos**: auxiliary connects stalled setup ~8s while the
  helper detected into an unread pipe; backlog replayed as toggle bursts.
- **Stale duplicate toggles**: single-consumer Win key-up, parity collapse
  (later reverted during bisect — see log).
- **Stuck mask/suppression**: hold state machine, orphan release, death
  hygiene on both ends.
- **Double reload churn**: config event plus mtime each ran the full
  reload; now one content-skipped path.

### Architecture

- **Single activation via helper** with generations, already-foreground
  early-out, and target/actual diagnostics on failure.
- **Dispatch ladder**: Win/numpad/single-tap demote to the hook with
  named reasons; already-in-use refusal demotes explicitly.
- **Foreground stack** for restore; transparent-hide instead of
  SW_HIDEWINDOW.
