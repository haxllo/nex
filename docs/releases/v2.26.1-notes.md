## Chat UI pass

Composer, dropdowns, hints and message chrome brought into one language.

## What changed

- Composer is a full-width docked bar with side controls and 8px corners.
- Model picker is a dropdown button; custom IDs enter via Use-query.
- One menu material, hover-reveal actions, custom delayed hints.
- Accent bar marks selection; fill follows hover.
