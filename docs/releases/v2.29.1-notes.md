## A new mark for nex

The app has a new icon. Same launcher, new face: the orange mark replaces the blue magnifier in the taskbar, the tray, the Start menu shortcut, the installer and the window.

## What changed

- **One icon source.** The mark is now a single vector, `apps/assets/nex.svg`, and everything else is generated from it — `16` through `512` px PNGs and the Windows `.ico` with `16, 20, 24, 32, 40, 48, 64, 96, 128` and `256` px frames.
- **All the places Windows reads an icon.** `Nex.exe` embeds the `.ico` (window, taskbar, Alt-Tab), the tray pulls it back out of the running exe, and the installer and shortcuts use the same file. Installing 2.29.1 over an older build refreshes the shortcut icon.
- **Small sizes are real frames.** The `.ico` carries every size from 16 through 256 px instead of one 256 px image that Windows squeezes, so Explorer and the tray pick a frame instead of shrinking a large one.
- **README** shows the new mark from the CDN, so the docs match what ships.

### Notes

- Nothing else changed: same binaries, same config, same behavior. This is a branding-only release.
- At 16 px the mark stays readable but is soft; the glyph fills as much of the frame as it can without touching the edge. If it reads muddy on your tray, tell us and we will ship a hand-tuned 16 px frame.
- The installer is still unsigned, so SmartScreen will warn exactly as it did for 2.29.0.
