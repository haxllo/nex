## An idle panel that earns its space

Until now the panel was a search bar with a short list of apps under it. This
release turns the empty state into something you can browse: an app list, tabs,
and a preview pane, with a compact mode for anyone who wants just the bar back.

## What changed

- **The idle panel is a browse view**: with nothing typed it lists your pinned
  apps first, then the ones you open most, then recently launched ones. The
  alphabetical tail only fills in when there is nothing else to show, so the
  panel is never a wall of everything installed.
- **Tabs filter the results**: All, Apps, Files and Folders, applied instantly
  on the client. Every show starts back on All, so the panel always opens in the
  same place.
- **A preview column sits beside the list**: icon, name, path and the details
  that matter for the selected row, at a fixed width so the list does not jump
  around as you arrow through results.
- **New View setting — Compact or Expanded**: Compact keeps the bare 60 px
  search bar and only shows results once you type. Expanded keeps the idle app
  feed. It applies live when you save, no restart.
- **The footer carries the app now**: brand mark on the left, an action list on
  the right that expands from a `⋯` trigger — Settings, GitHub, Website.
- **Panel is narrower**: 760 px instead of 880, so the expanded view reads as one
  column of content rather than a wide empty band.

### Bug Fixes

- **Pinning frequent or recent apps works**: the pin icon sends a path, and paths
  were being pushed through title lookup and bookmark URL validation. They no
  longer are — a path pins the app it points at.
- **Filesystem paths are never bookmarks**: bookmark URL normalization now
  rejects anything that looks like a local path instead of storing it as a
  broken `http://C:\...` entry.
- **Idle list no longer fills itself with whatever matches alphabetically** when
  you already had pins or usage history.
- **Launch counts survive an index refresh**: a rescan no longer resets the
  counters the idle feed sorts by.

### Notes

- The Quick Launch on/off switch is gone; **View → Compact** replaces it. If you
  had Quick Launch turned off, the upgrade lands you on Compact rather than
  filling your idle panel.
- Auto-fill is still its own preference: turn it off to keep the idle list to
  pinned apps only.
- Config is now version 25; the removed key is dropped on first launch.
