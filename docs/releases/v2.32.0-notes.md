## Results that use the whole panel, pins that stick

The right-hand preview column is gone, so results now run the full width of the
panel and nothing sits beside the list. Pinning from a search result finally acts
on the app you clicked, and "Open File Location" reaches the real folder behind a
Start-menu app.

## What changed

- **No more preview column**: the selected row is the whole story again — the
  list spans the panel and the detail column is removed. Grid and bento views
  keep their own layouts.
- **Empty tabs read properly**: "Nothing in this tab" now sits in the middle of
  the result area instead of dropping to the bottom under a blank list.
- **Command rows have glyphs**: built-in commands (create file/folder, web
  search, open URL, logs, config, clipboard, updates) draw an inline SVG mark, so
  they no longer look like broken rows with a blank icon slot.
- **Rows without icons line up**: command and calculator rows reserve the icon
  slot, so titles stop shifting left between mixed results.

### Bug Fixes

- **Pinning a result pins that result**: the pin icon on a result row sent the
  resolved launch path, which no quick-launch entry is stored under — so the icon
  never showed as pinned and clicking could pin an unrelated folder. It now sends
  the same identity the index and the context menu use, and the icon flips as
  soon as the pin lands.
- **Pinned items that cannot be resolved disappear instead of borrowing a row**:
  Quick Launch used to fall back to a loose substring match, which is how a
  leftover path pin surfaced as a folder named after your user directory. Pins
  are matched exactly now; anything unmatched simply is not shown.
- **Open File Location works for Start-menu apps**: discovered apps are stored as
  `shell:AppsFolder` aliases, and the resolver now handles all three shapes — a
  known-folder GUID with a file tail, a drive path embedded behind the alias, and
  a desktop app identifier resolved through the uninstall registry (Brave,
  Discord, Spotify). Microsoft Store app identifiers still have no file behind
  them, so those verbs stay hidden.
- **The pin/bookmark icon sits at the right edge of the row** instead of hugging
  the title.
- **The panel keeps its first frame on show**: the hotkey now re-kicks the reveal
  while the first paint is still pending, and DWM frame composition is suppressed
  on a host window that has never been shown, so opening the panel does not flash
  a stale picture.

### Notes

- The preview-pane work from this cycle (path line, usage stats, split Open
  button, action dropup) is parked on the `feature/preview-pane` branch and is
  not part of this release.
- Copy Path on an app copies the real executable path now rather than the
  `shell:AppsFolder` alias.
- Store-app rows (Calculator, Camera, Terminal) still show no Open File Location
  or Copy Path — there is no filesystem location to point at.
