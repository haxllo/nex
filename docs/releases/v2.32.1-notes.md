## The update notice stops loitering

A fix for the stray download icon that showed up next to What's new right after
you updated — even though Nex was already current.

## What changed

- **No more phantom Update pill after updating**: the first launch after an
  update arms the What's New entry point, which opens the small notice area in
  the search bar. The Update pill inside it was meant to stay hidden until an
  actual newer release was found, but the rule that hides it never applied, so
  it rendered as a bare download icon with no label. It now obeys the hidden
  state, and only appears when the update check really reports a newer version.
- **What's New is unaffected**: it still shows on the first launch after an
  update, and on installs that predate the notes feature.

### Bug Fixes

- **Update and What's New pills hide correctly**: both were hidden with an HTML
  `hidden` attribute that the stylesheet's own `display` rule overrode, so
  "hidden" never took effect. An explicit id-scoped hidden rule makes it real.
  A genuine update still shows both pills, and a failed update still surfaces
  its Retry button.
