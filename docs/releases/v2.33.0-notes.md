## Glass that works on laptops, and a cleaner first show

This release fixes the liquid-glass panel rendering as fully transparent on
hybrid-GPU laptops, adds an opaque fallback so a laptop that can never capture
its desktop no longer stays see-through, and cleans up the hover tooltips and
stale status text that flashed on show.

## What changed

- **Liquid glass now works on laptops**: on hybrid-GPU machines (Optimus / AMD
  dual) the display output lives on a different adapter than the one Nex picked,
  so every desktop-capture call failed and the glass never presented. Nex now
  creates its graphics device on the adapter that actually owns the panel's
  monitor.
- **Opaque fallback when capture is impossible**: if the desktop still can't be
  captured after a few seconds, Nex switches the panel to the solid acrylic
  fallback instead of staying transparent forever.
- **Lighter glass idle cost**: hidden idle passes now poll every 500 ms instead
  of 250 ms, and the per-second stats log fires every 5 s.
- **No more stray "Settings" popup on show**: the footer Settings hover tooltip
  could flash over the panel during the glass reveal; hover tooltips are now
  suppressed for the first 600 ms of a show.
- **No lingering "Settings applied" status**: saving settings no longer leaves a
  stale status line that resurfaces on the next show.
