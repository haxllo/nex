## Clean rounded edges for every panel

On Windows builds that support the relevant DWM attributes, black and white
panels now use a single native frame for their outline and rounded corners,
avoiding the extra or clipped edges that could appear around the panel. Older
Windows builds keep the existing CSS fallback. The first show uses the final
window geometry, and glass keeps its rounded clip across hide and show without
a stale one-pixel box flashing.

## What changed

- **Black and white panels have clean corners**: their outline and rounded
  silhouette now come from the same native frame, without a second CSS edge.
- **The first show matches later shows**: frame and surface geometry are synced
  before the panel is revealed, preventing the initial one-pixel mismatch.
- **Glass keeps its rounded clip**: frame sync leaves the main window region to
  the glass layer, so its cached clip stays installed through hide and show.

## Bug Fixes

- **Extra or clipped opaque-panel border**: the opaque outline no longer stops
  short of the rounded corners or overlaps the system frame.
- **Uneven first-show edges**: the native frame now follows the final window
  geometry before the first composition.
- **One-pixel glass border flash**: opaque frame sync no longer removes the
  glass layer's rounded host region behind its cache.
