## What's New notes are easier to read

The What's New page now shows the full release notes, including the release summary and complete change list. Longer notes scroll in their own area, while the “Got it” button stays available at the bottom.

## What changed

- **Complete release notes**: the page keeps the release title, summary, paragraphs, and all listed changes instead of trimming or truncating the content.
- **Easier reading**: long notes scroll independently, with the dismissal button remaining visible.

## Bug Fixes

- **Release notes cut off or missing**: all user-facing notes now appear in the What's New page.
