## Smarter compact bar and cleaner test gate

Quick Launch pins no longer stop at what fits on the compact bar — overflow
now scrolls with a visible affordance, and the bar no longer resets your
scroll while you type.

## What changed

- **Compact bar with many pins**: pinning more apps than fit used to just
  clip some icons at the edge with no hint anything was hidden → the row now
  scrolls, with `‹` / `›` buttons in dedicated slots at the edges (the side
  that still has content shows its arrow), sized so no pin is ever cut
  mid-icon.

### Bug Fixes

- **Pin scroll reset while typing**: each keystroke used to snap the pinned
  row back to the start if you had scrolled it → scroll position now
  survives typing, and only resets on reopen or when switching between
  compact and expanded views.
- **Failing local test run**: `pnpm vitest --run` kept picking up Jest-based
  suites from the bundled `third_party/codex` submodule and erroring → the
  gate now runs only nex's own suites and stays green.

### Notes

- Pinned counts remain uncapped; the 40% row width still caps how many are
  visible before scrolling.
