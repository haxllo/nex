## Pinned row holds its place

A regression fix on v2.36.0: the pinned row no longer jumps to a wrong
offset the first time you type after scrolling it.

## What changed

### Bug Fixes

- **Pin row jumped when you typed after scrolling**: the first typing push
  re-measured the pinned row while the bar's layout settled and the browser
  clamped the old scroll into an arbitrary position → the row re-anchors to
  the same first visible pin whenever the bar re-flows.
