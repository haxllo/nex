## Action list stops ghosting open

Bug-fix follow-up to v2.36.2: the expanded-view action flyout no longer
comes back expanded after you return to Nex.

## What changed

### Bug Fixes

- **Action flyout stuck open on reopen**: hover the actions in the footer,
  open Settings, close it, and reopen Nex — the list rendered expanded
  with no pointer near it. The window state survives a hide, and hover
  only re-checks when the mouse moves, which a hidden window never
  receives → the hover moment of the hide painted as-is on reopen.
  Hover now re-arms on every reopen instead of carrying over; hovering
  and keyboard focus behavior are unchanged.
