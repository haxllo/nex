## Search finds every file again

Files and folders under your discovery roots are now reliably searchable:
new downloads show up within a second, deep folders are indexed, and Nex
opens faster on large indexes.

## What changed

### Search & Indexing

- **New files show up right away**: the folder watcher stopped listening
  after its first batch of changes, so a new download such as
  `Downloads\message.txt` never reached search until a restart. It now
  keeps listening, restarts itself after errors, and rescans whenever it
  may have missed changes.
- **Everything indexed is searchable**: search no longer depends on a
  trimmed in-memory list of 5,000 items. Any indexed file or folder can be
  found, including in Folders mode and by words in the middle of a name.
- **Deep folders**: the 5-level depth limit is gone. The new
  `discovery_max_depth` setting defaults to `0` (unlimited).
- **Whole drives as roots**: when a root reaches its item cap, Nex keeps
  the shallowest files across every folder instead of filling the budget
  with one deep subtree. Raise `index_max_items_per_root` and
  `index_max_items_total` to index a whole drive.
- **Deleted and renamed folders** now leave results together with
  everything inside them.
- **Index self-repair**: starting Nex a second time no longer wipes the
  running copy's search index, and a damaged index rebuilds itself from the
  local database instead of coming back empty.

### Performance

- **Faster open**: the Quick Launch lookups that run every time Nex opens
  scanned the whole index (around 240 ms on large indexes); they now take
  about 1 ms. Index warming no longer runs before the window appears.
- **Compact view**: clearing the search collapses the bar immediately.
- Background indexing and cleanup no longer block typing or opening.

### Diagnostics

- `nex --probe-index` and the diagnostics bundle now show, for each root,
  how many files are on disk versus indexed, and whether a depth or item
  cap was hit.

### Bug Fixes

- **Compact view polish**: the gap between the What's new pill and the
  first pinned app is tighter, pills and pins show a single hint instead of
  a Windows tooltip plus Nex's own, and the hint is no longer clipped by
  the window edge.

### Upgrade Notes

- The first launch after updating upgrades the local index once (about a
  second on large indexes) and rescans your folders. Search keeps working
  while the rescan runs.
