## No more stray console window

2.38.0 started its background indexer with a visible console window, so
updating left a PowerShell-style window titled with the indexer path open
on the desktop. This update hides it, along with every other console helper
the app starts.

## What changed

### Bug Fixes

- **Stray console window**: after updating to 2.38.0, a console window
  titled `...\Programs\Nex\bin\NexIndexerProcess.exe` stayed open for as
  long as Nex ran. The indexer now starts with `CREATE_NO_WINDOW`, and the
  taskkill/tasklist helpers used by quit, restart, and status no longer
  flash a console either. Opening the logs folder is silent too.

### Notes

- Only `NexUIProcess`, `NexIndexer`, and `NexAdminAccess` should appear in
  Task Manager. A console window is no longer expected.

## Upgrade Notes

- Updating from 2.37.0 or 2.38.0 works in place.
- The one-release `bin\Nex.exe` launcher stays in the package so 2.37.0
  installs can still complete the in-app update; it is inert on 2.38.x.
