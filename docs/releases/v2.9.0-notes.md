## Highlights

- **Elevated helper binary.** New `apps/helper` workspace member (`NexHelper.exe`) runs at High IL via scheduled task, handling `SetForegroundWindow` from elevated windows (Task Manager, Settings).
- **Zero UAC after first run.** `ShellExecuteExW(runas)` replaced with a scheduled task — no UAC prompts on respawn.
- **Win key suppression.** `RIDEV_NOHOTKEYS` at RIT level replaces the `SendInput(0xE8)` race; Start menu reliably suppressed, Win key-up no longer stuck-down.
- **Installer flash elimination.** All CLI spawns during install replaced with direct registry writes and `taskkill` — no console flashes.
- **Packaging overhaul.** All 6 scripts bundle `NexHelper.exe`; Inno Setup uses registry for startup registration.
- **Just-in-time helper.** Helper no longer runs at boot — spawned on-demand via scheduled task when hotkey starts.
