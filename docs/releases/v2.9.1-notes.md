Fix launched programs opening behind overlay (WinRAR, Settings, File Explorer).

### Bug Fixes

- **Launched window behind overlay**: `hide_sync()` blocks until window is invisible before `ShellExecuteW`, so the spawned process naturally claims foreground instead of appearing behind the overlay. Also calls `AllowSetForegroundWindow(ASFW_ANY)` as additional safeguard.
