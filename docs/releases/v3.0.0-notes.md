## Nex 3.0.0

Chat can work on your files now. It reads, writes, edits, moves and deletes, runs PowerShell behind a confirmation card, and a conversation can carry a folder so "open last week's invoices" means something without a path.

The transcript, the settings panel and the media record were rebuilt around that. This release is 175 commits over twelve days.

## What changed

### Chat that acts

- Confirmation cards: heading, the exact target, and a filled primary action.
- One approval can cover the rest of a task; deleting, commands and unfamiliar links still ask every time.
- A card that times out says so instead of leaving the machine in an unknown state.
- `read_file` pages through a large file instead of reading both ends.
- Writing, editing in place, moving, copying, renaming and deleting, with deletes going to the Recycle Bin.
- Executable contents are flagged before a file is saved.
- `run_command` streams output while the command runs, so large output cannot wedge the pipe; Stop ends the command, not just the answer.
- A file created by a step is previewed in the transcript.
- Bare names resolve against the index and against user folders instead of walking the disk.
- A filesystem scope per conversation, set by chip, cleared by chip, and honoured mid-task when the model asks for one.
- A reply that hits the provider's output limit continues rather than ending mid-sentence, including on the OpenAI-compatible provider.
- A Continue control when the step limit is reached, and tool results survive a conversation reload.
- The model is told it is Nex and what version it is, and the capability list is derived from the tool declarations.
- PC facts are read when asked instead of riding on every request, and they are bounded.

### The transcript

- Rows for prompts, answers, actions and results, so a long conversation reads as a list.
- Markdown formats while it streams; code blocks are coloured and copyable.
- A running step reports what it is doing and, when it finishes, what it cost.
- A failure gets its own block, so one error no longer red-boxes the whole answer.
- Stop leaves a mark where the answer ended.
- The jump control lands back on the newest message, follows the theme, and is parked when it has nowhere to go.
- A permission card that opens below the fold is brought into view.

### Folder, settings and panel

- The conversation's working folder, with a list of what is inside it and an attach picker capped at three files.
- Settings and history are measured rather than assumed, and their menus no longer clip.
- Settings, history and the composer follow the glass theme.
- The chat settings footer puts its state on a line above one row of actions, with Save alone on the right.
- Tab opens Chat from the search box, and the placeholder says so.
- Closing a view keeps the panel at its full height.
- Compact view shows no hover hints, and its pills no longer double up with a native popup.

### Media

- Sessions are keyed per playing app, so switching players keeps the right track and the right dot.
- Album art is fetched per track with a comma-separated content type, retried when it is not ready, and replaced by a spinning record when absent.
- The media enumeration records what it saw and what it dropped.

### Hotkey, indexing and reliability

- The UI owns the detection pipe, so Win presses reach Nex; the helper connects as a client.
- One helper per save instead of a chain, and no console windows flashing on a hotkey change.
- F13 to F24 and bare F are valid hotkeys; the fallback id stays in range.
- Hotkeys stand down over a fullscreen game, and the tray reports it.
- The helper bounds its log and records panics; the hook thread no longer blocks on I/O.
- Quitting no longer freezes the UI behind a slow indexer.
- Log lines start with a local date and time.
- Uninstalling from the context menu returns to the panel instead of wedging the UI process.
- Indexing uses the saved USN journal on startup, one MFT snapshot per volume, and no full discovery pass on a directory delta.

### Notes

- The Windows helper needs elevation for hotkeys over elevated windows; that is unchanged.
- Telemetry: none. Nothing about a chat leaves the machine except the request to your chosen provider.
- Config migrations from older builds run on first launch.
